# Description
This repository contains proposed implementations of exercises and their descriptions. In this laboratory, you focus on designing simple algorithms and generic solutions for software architecture. The exercises are divided into four steps.

## Steps
* tr0_1 - implementation RPN algorithms
* tr0_2 - implementation generic solutions
* tr0_3 - preparing GUI and reusable current RPN implementation. If require refactor source code
* tr0_4 - integrate your library with my GUI
